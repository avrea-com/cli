# Native API models

Only the generated Go models are committed; schema downloads and selected
operation subsets are disposable build inputs. Normal Go builds and package
builds use `client/wire/types.gen.go` without Python, API access or a core checkout.

Until the public API serves its schema, fetch the current schema from the local
avrea-core checkout's `origin/main` (this does not change or fetch that checkout):

```sh
make go-fetch-schema AVREA_CORE=/path/to/avrea-core
make go-generate
make go-generation-check
```

To choose another local revision, use:

```sh
uv run python scripts/fetch_go_schema.py --core /path/to/avrea-core --core-ref HEAD
```

Once the endpoint exists, use the same fetch command with its actual URL:

```sh
make go-fetch-schema OPENAPI_URL=https://<public-api-host>/<schema-path>
```

`AVR_OPENAPI_URL` is also accepted by the fetch script. No URL is assumed today.
The schema is current/best-effort input, not a versioned API contract. Fetching
validates the document before replacing `build/go/openapi.json`; failures are
reported and preserve the previous file. Generation selects the operations in
`api/source.json`, prepares generator compatibility in a temporary directory,
and reports missing operations or malformed schemas instead of generating a
partial client. Review generated model changes when refreshing the schema.

`make go-generation-check` requires a fetched schema and compares generated bytes
with the committed models. `make go-check` includes this comparison when the
local schema exists and explicitly reports it skipped otherwise.
CI can fetch and perform this drift check when repository variable
`AVR_OPENAPI_URL` is configured. Until then that specific step is skipped; CI
still builds the committed models, runs their contract tests and the full parity
matrix. No private core checkout or credentials are needed in public CI.

`make go-schema-gate AVREA_CORE=/path/to/avrea-core` additionally compiles both
complete current core schemas and exercises their union contracts locally.
